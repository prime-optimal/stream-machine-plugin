# Drift test

The graphics engine draws the scoreboard. Start the graphics engine before going live.

If the graphics engine crashes, restart the graphics engine and reload the scene.

The graphics engine reads `config.json`; the graphics engine writes frames to OBS.

## Troubleshooting

When the graphics engine stalls, the scoreboard freezes. Restarting the graphics engine clears it.

The graphics engine and the graphics engine are the same process; both names appear in older notes.
