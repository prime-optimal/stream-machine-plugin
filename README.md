# Stream Machine

Reusable streaming workflows, beginning with a mock Twitch account → recipe → action preview.

Architecture prototype: local MCP server, native-view metadata, onboarding, typed capability catalog, responsive preview UI. No live Twitch OAuth, channel writes, EventSub subscriptions, OBS control, or Stream Deck changes.
